# Ticker (cinta de texto) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agregar un overlay de "ticker" (cinta de texto con scroll continuo), independiente del sistema de Graphs/Plantillas, controlable en vivo y con estilo configurable, más un acceso de navegación al panel de control en vivo que hoy no existe.

**Architecture:** Reusa el mecanismo ya existente para el badge "Vivo": una sección `ticker` en `display_config.json`, editada por secciones vía `POST /update_display_config`, leída por `GET /get_display_config`, y empujada en tiempo real por el SSE `GET /stream_display_config` que ya consume `pantalla.js`. No se crean tablas ni migraciones nuevas.

**Tech Stack:** Flask (blueprints, sin ORM para esta feature), JSON plano en disco (`display_config.json`), JS vanilla + Server-Sent Events en el frontend, Bootstrap 4 para los formularios de control.

## Global Constraints

- No hay framework de tests automatizados en este repo (no hay pytest ni carpeta `tests/`) — cada tarea se verifica manualmente con `curl` (backend) y con el navegador (frontend). No agregar un framework de testing nuevo solo para esto: fuera de alcance.
- El servidor se levanta con `python run.py` desde la raíz del repo (host `0.0.0.0`, puerto `5000`). `display_config.json` se lee/escribe con ruta relativa al cwd del proceso — correr `run.py` siempre desde la raíz del repo.
- El merge de `POST /update_display_config` es por sección: enviar solo las claves que cambian, nunca el objeto completo, para no pisar campos de otra pantalla de control.
- Seguir el patrón visual/estructural ya existente en `control_live.html` (Bootstrap 4, `config-section`) y en `pantalla.js` (`liveBadge`) — no introducir librerías o convenciones nuevas.

Agregar una función nueva `updateTicker`, antes de `function updateDisplay(data) {` (línea 70):

```js
function updateTicker(ticker) {
    const band = document.getElementById('tickerBand');
    const textEl = document.getElementById('tickerText');
    const cfg = ticker || {};

    if (!cfg.show) {
        band.style.display = 'none';
        tickerLastText = null;
        return;
    }

    band.style.top = cfg.top || '1000px';
    band.style.height = cfg.height || '50px';
    band.style.backgroundColor = cfg.bg_color || '#000000';
    textEl.style.color = cfg.color || '#ffffff';
    band.style.display = 'flex';

    const speed = parseFloat(cfg.speed_seconds) || 15;
    const text = cfg.text || '';

    if (text !== tickerLastText) {
        textEl.textContent = text;
        textEl.style.animation = 'none';
        void textEl.offsetWidth;
        textEl.style.animation = `ticker-scroll ${speed}s linear infinite`;
        tickerLastText = text;
    } else {
        textEl.style.animationDuration = `${speed}s`;
    }
}
```

Y llamarla desde `updateDisplay(data)`, como primera línea del cuerpo de la función (línea 71, antes de `const liveBadge = ...`):

```js
    updateTicker(data.ticker);
```

```html
    <script>
        document.addEventListener('DOMContentLoaded', async function () {
            const tickerShow = document.getElementById('tickerShow');
            const tickerText = document.getElementById('tickerText');

            try {
                const response = await fetch('/get_display_config');
                const config = await response.json();
                if (config.ticker) {
                    tickerShow.checked = !!config.ticker.show;
                    tickerText.value = config.ticker.text || '';
                }
            } catch (error) {
                console.error('Error al cargar configuración del ticker:', error);
            }

            function guardarTicker() {
                fetch('/update_display_config', {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify({
                        ticker: {
                            show: tickerShow.checked,
                            text: tickerText.value
                        }
                    })
                }).catch(error => console.error('Error al guardar el ticker:', error));
            }

            tickerShow.addEventListener('change', guardarTicker);
            tickerText.addEventListener('blur', guardarTicker);
        });
    </script>
{% endblock body %}
```
